# 🥄 ביס ראשון

אפליקציית ווב (PWA) בעברית למעקב אחר הטעימות של התינוק ולשמירה על חשיפה קבועה לאלרגנים.

## מה יש בה
- **מעל 70 מוצרים** בקטגוריות: ירקות, פירות, דגנים, חלבונים, קטניות, מוצרי חלב ואלרגנים. לכל מוצר יש אנימציה משלו, טיפ הגשה, ואזהרת חנק כשצריך.
- **סימון מיוחד לאלרגנים:** תג ⭐, מסגרת מקווקוות וכרטיס הסבר על דרך ההכנסה.
- **מסך אלרגנים:** סטטוס לכל אלרגן (עוד לא נחשף, בשלב היכרות, בשמירה, חשד לתגובה), טבעת התקדמות שבועית ונקודות לימי החשיפה.
- **תזכורות:** תזכורת צהובה כשמתקרבים לגבול, ואדומה כשעבר יותר מדי זמן מהחשיפה האחרונה. בנוסף, הצעה לאלרגן הבא שכדאי להכיר (אחד בכל פעם, עם הפרש של יומיים לפחות).
- **רישום טעימה:** זמן, תגובת התינוק, כמות, תסמינים והערות. בחירה בתסמין חמור מציגה מיד הנחיית חירום עם קישור לחיוג 101.
- **מונה חשיפות** עם יעד של 10 טעימות למוצר, ומסרי עידוד כשמוצר לא אהוב.
- **יומן** של כל הטעימות לפי ימים.
- **מדריך** מבוסס מחקר, עם קישורים למקורות (ראו [RESEARCH.md](RESEARCH.md)).
- **תזכורות ביומן:** קובץ `.ics` עם אירועים חוזרים לכל אלרגן, לפי היעד השבועי שהוגדר.
- **התראות דפדפן** (אפשר להפעיל בהגדרות).
- הוספת מוצרים משלכם, גיבוי ושחזור (ייצוא וייבוא JSON), מצב כהה, ועבודה גם בלי חיבור לרשת.

## הרצה
אין צורך בהתקנה או בבנייה:

```bash
python3 -m http.server 8000
# ואז לפתוח את http://localhost:8000
```

אפשר גם לפרסם את התיקייה כמו שהיא ב-GitHub Pages, Netlify או כל אחסון סטטי אחר. אחר כך פותחים את האתר בטלפון ובוחרים "הוסף למסך הבית".

## הערות
- כל הנתונים נשמרים **רק במכשיר**, ב-localStorage. כדאי לגבות מדי פעם דרך ההגדרות.
- התראות דפדפן מוצגות כשהאפליקציה פתוחה או נפתחת. כדי לקבל תזכורות גם כשהיא סגורה, השתמשו בייצוא ליומן.
- ⚕️ האפליקציה היא כלי מעקב ומידע כללי, **ואינה תחליף לייעוץ רפואי**.
