# 🥄 ביס ראשון

אפליקציית ווב (PWA) בעברית למעקב אחר הטעימות של התינוק ולשמירה על חשיפה קבועה לאלרגנים.

## מה יש בה
- **התחברות:** הרשמה וכניסה עם מייל וסיסמה. אפשר כמה חשבונות על אותו מכשיר, והנתונים של כל חשבון נשמרים בנפרד. הסיסמה נשמרת כ-hash (PBKDF2 + salt).
- **שאלון פתיחה קצר:**
  1. השם שלך (שם האמא).
  2. שם הילד/ה ותאריך לידה, עם חישוב גיל.
  3. אווטאר: מעלים תמונה, ממקמים ומגדילים אותה בתוך העיגול, ובוחרים צבע מסגרת וקישוט. אפשר גם לבחור דמות במקום תמונה. האווטאר מופיע בכותרת, בכרטיס הפתיחה ובחגיגות.
  4. אלרגנים שכבר נחשף/ה אליהם: עוד לא, טעם/ה, אוכל/ת קבוע, או הייתה תגובה.
  5. מוצרים שכבר טעם/ה, עם בחירה מהירה לפי קטגוריה.

  התשובות נרשמות כחשיפות, כך שהסטטוסים והתזכורות מתחילים נכון בלי להזין הכל מחדש.
- **מעל 70 מוצרים** בקטגוריות: ירקות, פירות, דגנים, חלבונים, קטניות, מוצרי חלב ואלרגנים. לכל מוצר יש אנימציה משלו, טיפ הגשה, ואזהרת חנק כשצריך.
- **סימון מיוחד לאלרגנים:** תג ⭐, מסגרת מקווקוות וכרטיס הסבר על דרך ההכנסה.
- **מסך אלרגנים:** סטטוס לכל אלרגן (עוד לא נחשף, בשלב היכרות, בשמירה, חשד לתגובה), טבעת התקדמות שבועית ונקודות לימי החשיפה.
- **תזכורות:** תזכורת צהובה כשמתקרבים לגבול, ואדומה כשעבר יותר מדי זמן מהחשיפה האחרונה. בנוסף, הצעה לאלרגן הבא שכדאי להכיר (אחד בכל פעם, עם הפרש של יומיים לפחות).
- **רישום טעימה:** זמן, תגובת התינוק, כמות, תסמינים והערות. בחירה בתסמין חמור מציגה מיד הנחיית חירום עם קישור לחיוג 101.
- **מונה חשיפות** עם יעד של 10 טעימות למוצר, ומסרי עידוד כשמוצר לא אהוב.
- **פתקי חוכמה:** 44 פתקים בעיצוב של פתקים מודבקים, בשש קטגוריות (אלרגנים, טעימות, בטיחות, תזונה, טריקים במטבח, הורות רגועה). אפשר לשמור פתקים אהובים, ובמסך הבית מופיע פתק יומי.
- **מתכונים:** 28 מתכונים עם גיל מומלץ, מרקם, זמן הכנה וסימון אלרגנים. אפשר לסנן לפי גיל ותגיות, ומתכון שיש בו אלרגן שעוד לא הוכר מקבל אזהרה. הכפתור "הכנו!" רושם טעימה לכל המרכיבים בבת אחת.
- **מתכון מומלץ להיום:** נבחר לפי האלרגנים שצריך לשמור עליהם, ובתזכורות יש קישור "💡 רעיון" למתכון מתאים.
- **שילובי טעמים מנצחים:** 16 צמדים מהירים.
- **יומן** של כל הטעימות לפי ימים.
- **מדריך** מבוסס מחקר, עם קישורים למקורות (ראו [RESEARCH.md](RESEARCH.md)).
- **תזכורות ביומן:** קובץ `.ics` עם אירועים חוזרים לכל אלרגן, לפי היעד השבועי שהוגדר.
- **התראות דפדפן** (אפשר להפעיל בהגדרות).
- הוספת מוצרים משלכם, גיבוי ושחזור (ייצוא וייבוא JSON), מצב כהה, ועבודה גם בלי חיבור לרשת.

## הרצה
אין צורך בהתקנה או בבנייה:

```bash
python3 -m http.server 8000
# ואז לפתוח את http://localhost:8000
```

שימו לב: ההתחברות דורשת כתובת מאובטחת (https או localhost). אפשר גם לפרסם את התיקייה כמו שהיא ב-GitHub Pages, Netlify או כל אחסון סטטי אחר. אחר כך פותחים את האתר בטלפון ובוחרים "הוסף למסך הבית".

## הערות
- החשבונות והנתונים נשמרים **רק במכשיר**, ואין שרת. סנכרון בין מכשירים (למשל בין שני ההורים) יחייב חיבור לשירות ענן כמו Firebase או Supabase. גם שחזור סיסמה לא אפשרי בלי שרת, ולכן כדאי לגבות.
- כל הנתונים נשמרים **רק במכשיר**, ב-localStorage. כדאי לגבות מדי פעם דרך ההגדרות.
- התראות דפדפן מוצגות כשהאפליקציה פתוחה או נפתחת. כדי לקבל תזכורות גם כשהיא סגורה, השתמשו בייצוא ליומן.
- ⚕️ האפליקציה היא כלי מעקב ומידע כללי, **ואינה תחליף לייעוץ רפואי**.
